# Sayani Birthday Website

A self-contained interactive birthday website inspired by the uploaded reference video.

## Open it
Double-click `index.html` to open it in Chrome/Edge.

## Personalize it
Open `index.html` in a text editor and change:
- `Sayani` -> the recipient's name
- `Aritra` -> your name
- The paragraphs in the letter/final section -> your own message

## Add photos
When the website is open, tap the four photo boxes and choose photos from your device.

## Add music
Tap `+ add your song` and choose an MP3/audio file. The browser plays it locally; the audio file is not uploaded anywhere.

## Publish online
Upload `index.html`, `style.css`, and `script.js` to GitHub Pages, Netlify, Vercel, or another static hosting service.

No backend is required.
